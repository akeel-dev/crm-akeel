## Objetivo

Existe o esqueleto da SPA: `npm ci && npm test` roda, `npm run build` gera a pasta
estática, e a aplicação tem roteador, cliente de cache de dados e uma biblioteca de i18n
com o catálogo pt-BR. Nenhuma tela de negócio.

## Critério de aceite

1. **Dado** um clone limpo com Node `>=22.12`, **quando** se roda
   `npm ci --no-audit --no-fund && npm test`, **então** sai com 0; `npm test` roda o
   verificador de tipos (`tsc` sem emitir) **e** o Vitest, e falha se qualquer um falhar.
2. **Dado** `npm run build`, **quando** termina, **então** gera a pasta estática sem aviso de
   tipo.
3. **Dado** a aplicação montada num teste, **quando** abre a rota raiz, **então** mostra um
   texto que vem do catálogo pt-BR (o teste lê o texto do catálogo, não o repete).
4. **Dado** uma rota que não existe, **quando** acessada, **então** a aplicação mostra a
   página "não encontrada" em pt-BR, vinda do catálogo.
5. **Dado** `src/`, **quando** o lint roda, **então** passa, e um texto de interface escrito
   direto num componente (sabotagem: um `<p>Olá</p>`) é acusado por regra de lint ou por
   teste. Sabotagem registrada e desfeita. *Se não houver regra pronta que faça isso sem
   falso positivo demais, o QA registra a evidência e a checagem vira item do Revisor.*
6. **Dado** `package.json`, **quando** se lê, **então** declara `engines.node` compatível com
   o Vite (`>=22.12`) e os scripts `test`, `build`, `lint`.
