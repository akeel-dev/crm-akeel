# Story 0-05 — O backend compila em Java 25, sobe e migra contra um PostgreSQL real

Dono: Planejador. Congela quando o QA é despachado; depois disso, achado vai para
`conflitos/`.

**Onda:** 0 · **Repositório:** `backend/` (commits do QA e do Dev, no mesmo repositório)
**Requisitos da spec:** D-03, D-05, §4.2 (Spring Boot 4, Flyway, jOOQ, Testcontainers), §12 (integração com PostgreSQL real, nunca banco em memória; relógio injetável e fuso `America/Sao_Paulo`); ADR 0001, decisões 1 a 3 e linhas "Java 25 / Spring Boot 4" e "PostgreSQL 17+" de "Guardado por"
**Rigor:** leve
**Depende de:** 0-01

## Objetivo

Existe o esqueleto do backend: `./mvnw -B verify` roda, recusa JDK abaixo de 25, sobe o
contexto Spring contra um PostgreSQL em Testcontainers, aplica as migrações Flyway e expõe
um relógio injetável. Nenhum módulo de negócio é criado.

## Critério de aceite

1. **Dado** o JDK 25, **quando** se roda `./mvnw -B verify`, **então** o build passa, com o
   `parent` em `spring-boot-starter-parent` 4.2.x e `maven.compiler.release=25`.
2. **Dado** um JDK abaixo de 25 (sabotagem: `JAVA_HOME` apontando para o 17 da máquina),
   **quando** se roda `./mvnw -B verify`, **então** o `maven-enforcer-plugin`
   (`requireJavaVersion [25,)`) falha **antes** dos testes. Saída registrada.
3. **Dado** o contexto da aplicação num teste de integração com PostgreSQL em
   Testcontainers (`postgres:18`), **quando** sobe, **então** o Flyway aplica as migrações do
   esqueleto sem erro e a tabela de histórico do Flyway existe.
4. **Dado** o mesmo contêiner, **quando** um teste lê `server_version_num`, **então** é
   `>= 170000` (D-05). Ele falharia com uma imagem `postgres:16` (sabotagem registrada).
5. **Dado** o contexto, **quando** um teste pede um `java.time.Clock`, **então** recebe um
   bean substituível nos testes, com fuso `America/Sao_Paulo` explícito (§12). Uma
   migração que crie `pg_trgm`, `unaccent` e `citext` roda sem erro (§4.2 busca; §6.3
   `app_user.email citext`).
6. **Dado** o pacote base `br.com.akeel.crm`, **quando** se lista `src/main/java`, **então**
   só existe a classe de aplicação e o que o critério 5 exige; nenhum pacote de módulo.

## Passos e papéis

1. **QA:** escreve os testes dos critérios 3 a 5; como ainda não há `pom.xml`, o vermelho
   esperado é "não compila / não há build". O QA registra isso e o Dev parte dele.
   *Exceção registrada:* nesta story o QA pode precisar do `pom.xml` mínimo para provar o
   vermelho pelo motivo certo; se precisar, abre `conflitos/qa-0-05-pom.md` em vez de
   escrever no arquivo do Dev.
2. **Dev:** `pom.xml` (Spring Boot 4.2.x, Flyway, jOOQ sem geração de código, Testcontainers,
   enforcer), wrapper, classe de aplicação, `Clock`, a migração das extensões.
3. **Revisor:** confere a sabotagem do critério 2 e do 4.
