## Objetivo

O workflow de CI do frontend existe e cada passo roda localmente pelo mesmo comando; o
`frontend/Dockerfile` produz uma imagem que serve a SPA estática.

## Critério de aceite

1. **Dado** `frontend/.github/workflows/`, **quando** se roda o actionlint por contêiner,
   **então** sai com 0.
2. **Dado** o workflow, **quando** se lê, **então** os passos são: `comandos.suite_frontend`;
   lint; `npm audit --audit-level=high` (falha com alta ou crítica); `npm run build`; build
   da imagem.
3. **Dado** a máquina local, **quando** se rodam os comandos de cada passo, na ordem,
   **então** todos saem com 0. Vulnerabilidade alta ou crítica achada pelo `npm audit` vai
   para `conflitos/devops-0-15-audit.md` (as dependências são do Dev), não é silenciada.
4. **Dado** `docker build frontend/`, **quando** a imagem roda, **então** serve o
   `index.html` na raiz e em qualquer rota desconhecida da SPA (o roteador é do cliente),
   roda como usuário não root e não contém `node_modules` nem o código-fonte.
5. **Dado** a imagem, **quando** se procura credencial, **então** não há nenhuma.

